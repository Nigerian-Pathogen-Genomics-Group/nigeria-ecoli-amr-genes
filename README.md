# Genomic Survey of AMR Genes in Nigerian E. coli

Part of the Nigerian Nextflow community research group.

## Aim
Describe the antimicrobial resistance (AMR) gene profiles of publicly available
Nigerian E. coli genomes (Lagos, Ibadan, Edo).

## Data
Public isolates from NCBI Pathogen Detection (see data/).
